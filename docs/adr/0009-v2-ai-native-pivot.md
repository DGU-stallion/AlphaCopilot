# ADR-0009 — v2 转向：AI native（本 ADR 是 0010–0013 的总纲）

**状态**：已决定（**2026-10-21 修订**：ADR-0011 的后端语言决定改为「保 Python」，
见其 §0；本 ADR 的转向结论不变）
**日期**：2026-10-20 · 修订 2026-10-21
**取代**：ADR-0008 的「AI 只解释」与「AI 不生成计算结果」
**继承**：ADR-0008 的固定业务页面骨架、四个导航分组、不做实盘/多智能体辩论的边界

## 背景

ADR-0008（2026-09-05）把产品定成「确定性计算为主 + AI 只解释」，理由是早期
「对话驱动 + AI 写 Python + 页面可生长」导致反复大改。这个调整在当时是对的：
它把项目从「AI 什么都要生成」拉回到「先把确定性平台跑通」。

一个半月后复盘，暴露出 ADR-0008 自身的问题：

1. **AI 的价值被压得几乎没有**。只解释当前页面数据 → 与「高级搜索框」无异。
   M2 时代已经跑通过的那条链（agent 写 Python → 产 ECharts → 进对话流，
   见 `test_e2e1_correlation.py`，90 秒端到端）被判定为「不该是核心」而废弃，
   前端四个 block 渲染器在 `dbe7b6e` 被删。
2. **管道与定位错配**。后端保留了完整的 `run_python` + Seatbelt + artifact + job，
   前端却没有渲染器——两头都不通。
3. **AI 层事实上是断的**。dsh 依赖外部目录，8 个测试红了一个多月无人发现（无 CI）。

## 决定

### 转向 AI native，用四条 ADR 落地

| ADR | 决定 |
|---|---|
| **0010** | Agent 运行时改用 **Pi SDK**，授予**完整工具集（含 bash）** |
| **0011** | 应用层/Agent 层迁移 **Node + TypeScript**；Python 保留为**内部数据服务** |
| **0012** | **双轨产物规则**：确定性结果 vs Agent 表达，用 provenance 区分 |
| **0013** | UI 换为**交易终端风 + 双主题 + Lightweight Charts** |

### 与 ADR-0008 的关系

**被取代**：
- 「AI 只解释」（0010 给了完整能力）
- 「不生成计算结果」（0012 允许 agent 产 artifact，但**数字仍只来自确定性函数**）
- 「固定业务页 vs page spec 二分」（0012 改为 View/Page 对象模型）

**继续有效**：
- 不做实盘下单 / 盯盘 / 个股行情终端
- 不做多智能体辩论 / 分析师团队
- 不做多用户 / 权限 / SaaS
- 不荐股、不预测涨跌、不给买卖时机的合规底线（降级为 prompt 层约束）

### 一句话的新定位

> **AI native 的个人投研量化工作台：确定性计算提供可信数字，agent 提供探索与表达。**

## 权衡

- **为什么不是「渐进加 AI 功能」**：dsh 已坏、定位文档与实际代码互相矛盾、
  数据层一半是死代码。渐进会在错的地基上继续叠加。
- **为什么敢放开 agent 能力**：个人本机、无实盘、无他人数据、可接受重装成本
  （用户明确判断）。残余风险在 ADR-0010 §3 显式记录，不静默接受。
- **为什么保留 Python**：akshare 无 TS 等价物；回测引擎是 A 股规则沉淀；
  因子/量化生态（qlib / vectorbt / alphalens）只在 Python。数据层包一层 HTTP
  的成本（2–3 天）远低于重写（3–4 周）。

## 修订（2026-10-21）

四条子 ADR 中，**ADR-0011 的后端语言部分被修改**（后端不做 TS 重写）。
其余三条（0010 Pi + 完整能力、0012 双轨产物、0013 UI 系统）方向不变，
各自补了「落地缺口」的修订节：

| ADR | 修订内容 |
|---|---|
| 0010 | RPC 模式下 MCP/skills 的挂载方式（`PI_CODING_AGENT_DIR` + `--approve`）；skills 改为白名单 30 个 |
| 0011 | **后端保留 Python**，不重写；去掉 `MarketDataPort`；monorepo 只是搬目录 |
| 0012 | provenance 与 Pin/View 目前**未实现**，给出 M1-7 / M3-3 排期；block 需 `renderer` 判别符 |
| 0013 | 不变（只新增 M2-5 的判别符交接） |

**本转向的核心论断仍然成立**：确定性的那层是健康的，AI 那层断了且没人知道
（无 CI、8 个测试红）。这一点已实测确认。
