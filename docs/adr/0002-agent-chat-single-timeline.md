# ADR-0002 — Agent 对话采用单时间线布局，图表内联嵌入

**状态**：已决定  
**日期**：2026-07-26

## 背景

Agent 对话页需要同时展示：
1. 多 agent 协作的中间过程（谁在做什么）
2. 最终的交互式图表和结论

有两种布局选项：
- **左右分栏**：左侧协作过程，右侧结果
- **单时间线**：协作步骤和图表结果按时间顺序从上到下排列，类似 ChatGPT

## 决定

采用**单时间线布局**：用户输入、各 agent 工作步骤、图表、结论，全部从上到下按时间顺序排列在同一对话流中。交互式图表作为消息气泡嵌入，不跳转新页面。

## 权衡

- 左右分栏更"专业"，但在个人使用场景下增加了认知负担，且在窄屏上体验差
- 单时间线与用户已熟悉的 AI 对话工具（ChatGPT、Claude）交互模式一致，学习成本为零
- 图表内联而非新页面，保持对话上下文连续性

## 影响

- Agent 每个工作步骤需要设计折叠/展开交互（默认折叠，避免冗长）
- 图表组件需要响应式，适配对话流的宽度约束
