# D-B「Linear / Vercel」原型

复盘看板 + 宏观看板的静态原型，验证 **中高密度** 方向（REFACTOR-PLAN ROUND2 §4.1）。

## 规格落实

| 项 | 值 | 落实方式 |
|---|---|---|
| 主字号 | 13px | body 基准；20px 仅用于关键指标大数字，16px 仅页标 |
| 次字号 | 12px | 表格、报价卡、行列表 |
| 行高 | 1.4 | body 全局 |
| panel 间距 | 12px | grid gap / flex gap 统一 12px |
| 圆角 | 2 / 4px | chip 2px、卡片与指标 4px（≤6px 上限内） |
| 数字 | tabular-nums + JetBrains Mono 栈 | 所有数值元素 |
| 颜色 | 全部来自 `frontend/src/theme/tokens.ts` DARK | 14 个 token，无第 15 个色值 |

禁令自查（已 grep 验证）：无 `linear-gradient` / `radial-gradient`、无 `box-shadow`、
无 `backdrop-filter`、圆角最大 4px。图表为**内联 SVG 手绘**（上证指数近 60 日折线 +
美债收益率柱状），无 ECharts、无 CDN、无外部依赖。

## 「这一屏我看到了什么、下一眼该看哪」

**第一眼**：左栏顶部一排 5 张关键指标卡——上证指数 `3,321.45 (+1.23%)`、
两市成交额 `18,542 亿`、涨跌家数 `3,247/1,856`、涨停跌停 `78/6`、最高连板 `5 板`。
这是今天复盘的全部结论层，20px 大数字 + 红绿着色，扫一行即有盘面概念。

**第二眼**：想验证「涨」的成色 → 左中两张图：上证近 60 日走势（为什么涨）+
右侧打板情绪（封板率 71.2% / 炸板率 28.8% / 晋级率 32.5%）与连板梯队
（谁在带节奏）。

**第三眼**：想知道钱往哪去 → 底部板块资金表，按净流入排序，红正绿负一眼分多空。

**右栏（宏观看板）**是低频参照系：隔夜外围 + 美债收益率 + 大宗 + 汇率，只在
「今天 A 股为什么这么走」时才看；底部的「盘面速记」带 AI 角标（provenance: agent），
与上方 deterministic 数字明确区分。

## 与另外两版对照的预期差异

- 比 **D-A 彭博终端**（12/11px、8px 间距）：同样一屏内容下多 ~1px 呼吸感，
  表格行高 25px 仍可长时间阅读，但极限密度低一档（本屏约 7 个 panel vs D-A 可塞 10+）
- 比 **D-C 杂志**（14/13px、20px 间距）：信息量明显更高，但叙事感弱——
  适合「看数据」不适合「读研报」

## 如实评价（缺点）

1. **左右两栏信息量不均**：复盘栏 7 个区块 vs 宏观栏 7 个但每块更薄；1440px 视口下
   两栏并排是原型需要（一屏比两版），落地时宏观看板应独占一页
2. **大数字 20px 与 13px 正文对比强烈但略突兀**：指标卡高度依赖这层对比，
   如果用户觉得「跳」，降到 18px 仍成立
3. **无交互**：表格排序、图上 hover 十字光标都只是静态暗示，密度观感在真实
   交互（选中行高亮、tooltip）下会略变
4. **数字为手工编造的真实感数据**：量级合理（18,542 亿成交额、78 家涨停符合
   2026 年市场常态）但非当日真实行情
5. **宏观栏 AI 速记只有一行**：agent 文本在 400px 窄栏下的长文可读性未验证，
   需要真实归因文本（多段落）再测
