# D-C 「杂志式」原型

复刻 `docs/ROUND2-BRIEF.md` §4.1 定义的 D-C 方向：**14px 主字号 / 13px 次字号 /
行高 1.6 / panel 间距 20px / 大标题 / 留白做层次**。

- `index.html` —— 自包含单文件（内联 CSS + 内联 JS，无 CDN、无构建）
- `screenshot.png` —— Playwright 1440×900 视口全页截图（实际全页高 1507px）

## 这一屏我看到了什么、下一眼该看哪

**第一眼**：大标题「普涨收官：沪指站上 3,290，量能重回 1.7 万亿」——
页面上最大的元素，标题里的关键数字直接用涨跌色点出结论，
这一眼就知道今天盘面是什么性质（放量普涨）。

**第二眼**：标题正下方的五个大数字卡（上证 / 深成 / 创业板 / 成交额 / 涨跌家数）。
26px 的等宽数字是整屏第二档视觉重量，三个指数全红 + 成交额放大 21.4%，
把标题的结论用数字坐实。

**第三眼**：往下分两栏——左宽右窄。左栏「复盘」三块自上而下：
分时折线（今天的走势形状）→ 情绪六格（涨停/连板/封板率）→
行业资金横柱（谁进谁出）；右栏「宏观」三块：隔夜外围 → 大宗与汇率 →
美债收益率曲线。视线自然从「今天 A 股怎么样」滑到「外围环境给它什么背景」。

**回头细看**：导语段落把结构性信息放在这里（银行白酒逆势流出、风格分歧），
对应左栏柱状图底部两根绿条——读完标题和数字后，导语是第二次入口。

排版层级是明确的上→下四级：期号行 → 大标题+导语 → 关键指标大数字 →
明细图表与清单，页脚收口径说明。

## D-C 特征在这张图里的体现

- 留白本身承担分组职责：panel 之间 20px、栏目题与内容之间靠细线 + 空行，
  不靠边框堆叠出层次
- 行高 1.6 让导语和明细行都能长阅读，数字区行高压到 1.2–1.3 保块面感
- 大标题承载叙事（今天发生了什么），数字卡承载事实，明细承载证据——
  这是与 D-A（表格式塞满）和 D-B（紧凑卡片）最本质的区别

## 如实的缺点（密度观感）

- **信息量明显低于 D-A/D-B**：1440×900 首屏只放下标题 + 导语 + 五张数字卡，
  图表全部在折叠线以下。一屏多数据是自用刚需，D-C 在这一点上有先天劣势
- **右栏偏空**：宏观内容本身少（brief §1.2 已指出是内容不足不是排版问题），
  三块明细行排完后与左栏高度不齐，底部留了一截
- 明细行（右栏的外围/大宗）采用「名称+价格+涨跌」三列行式，
  没有 D-A 表格的列对齐能力，数据列数一多就会退化为列表
- 大标题占用的情感化叙事写法（「普涨收官」）对每日复盘要人手拟，
  自动生成时容易变成无信息量的套话

## 颜色与硬规则自查

- 全部 hex 值来自 `frontend/src/theme/tokens.ts` DARK 调色板（14 个，逐一比对过），
  无 palette 之外的颜色
- 涨红 `#D9534F` / 跌绿 `#3FAE7A`（A 股口径），外围市场沿用红涨
- 无渐变、无 box-shadow、无 backdrop-filter；圆角只有 2px（标签）/ 6px（卡片）
- 数字全部 `font-family: JetBrains Mono` 栈 + `font-variant-numeric: tabular-nums`
