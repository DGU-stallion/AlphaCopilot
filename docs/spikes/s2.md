## 验证目标

双半体单包插件：host 半体注册用户命令 `/chart-demo` 向当前会话 append 自定义事件
`chart/plot`；client 半体把它折叠成 chat 视图节点，并用 keyed renderer 渲染纯 SVG 双线折线图。
验证「对话流中渲染折线图」全链路可行。

### 关键实现点

1. **命令 API（实测 dsh-commands 源码确认）**
   `ctx.commands.register({ name, description, handler })`，handler 收到
   `{ commandId, agent, rawInput, attachments, signal }`，**session 在 `invocation.agent.session`**，
   append 形式即 `invocation.agent.session.append('chart/plot', data)`。handler 可 async，
   返回 `{kind:'success', text}` / `{kind:'error', text}`。append 包 try/catch +
   `ctx.logger.warn`。host inject = `["commands"]`。
2. **事件族 Definition（逐字模仿 ui-workflow-run 的 workflowRunDefinition）**
   单事件族：`match` 对 `chart/plot` 返回 `{id: String(data.chartId), role: 'start'}`；
   `start` 从 `match.event.data` 折叠 state（title/norm/series）；`update` 原样返回 state；
   **`location` 直接取框架算好的 `context.start.location`，不要手搓**；
   `anchorSeq = context.start.event.seq`。
3. **keyed renderer**：`ctx.slots.inject('conversation.chat.node', () =>
   ctx.slots.register({ name:'conversation.chat.node', key:'chart.plot' }, ChartNodeView))`，
   组件 props 含 `node`（conversation 内部把 routedNode 塞进 owner 再分发）。
4. **SVG 渲染**：react/jsx-runtime 手写 jsx 调用（无构建、无 JSX 语法），viewBox 640×300，
   4 条网格线 + y 刻度、首/中/尾 x 日期刻度、每系列 polyline+圆点+legend 文字，
   两系列固定色 `#2563eb`/`#dc2626`。零图表库。
5. **数据生成**：Math.sin 双相位叠加 ×20 点，起始 2026-07-01，茅台/五粮液两系列。

## 发现的坑（修正了任务书假设）

1. **`dsh --profile alphacopilot web` 在 rc.2 直接报错**：
   `error: web takes none of parent --profile, --patch, ...` —— `web` 子命令是
   `--profile web` 的硬编码别名，且 alphacopilot profile 没有 `@deepseek-ai/dsh-web-app`
   bundle。实际验证改为：临时把本包装进默认 web profile 启动探活，结束后 remove 还原。
   正式路径待 T14a（web panel spike）解决「自定义 profile 如何带前端」。
2. **`plugin add -w` 相对路径锚定不可靠**：从 `docs/spikes/s2` 传 `../../packages/...`
   被解析成 `<repo>/docs/packages/...`（不存在），pnpm 照样写入死链且报
   "declares no dsh.bundle"。**一律用绝对路径**。
3. **match 结果会被框架富化**：调 `start/update` 前 conversationEvents 引擎把
   原始 event 挂进 match（`match.event`），草稿里自己拼 event 的写法多余。
4. **location 是引擎产物**：ui-conversation 的 `chatNode()` helper 显示
   `location ??= contextLocation(context)`（来自 `context.start.location`），
   手写 `{kind:'step',...}` 会丢 turn/step 闭包信息。
5. 命令名正则 `/^[a-z][a-z0-9_-]*$/u`，`description` 必填非空——normalizeDefinition
   在注册时强校验。
