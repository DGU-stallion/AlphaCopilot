# S1 Spike — dsh bundle 安装流程验证（T05）

**日期**：2026-08-26 · **结论：✅ 通过**

## 验证目标

bundle 安装 → profile 组合 → dump-config 生效的完整链路；独立 profile 与本机默认 dsh 隔离。

## 环境

- dsh `@deepseek-ai/dsh@0.1.1-rc.2`（npx）
- 本机已有默认 profile `web`（含 dsh-context、dsh-agent-team-gui）

## 步骤与结果

```bash
cd docs/spikes/s1
npx @deepseek-ai/dsh plugin --profile alphacopilot add -w ./hello-plugin
# → 初始化 ~/.dsh/profiles/alphacopilot（bundles: [@deepseek-ai/dsh-base, acp-hello-plugin]）

npx @deepseek-ai/dsh --profile alphacopilot --dump-config | grep acp-hello
# → 合成配置中出现:
#   # == acp-hello-plugin
#   - id: acp-hello
#     name: acp-hello-plugin
```

## 关键发现（修正了计划中的假设）

1. **patch 文件格式是顶层数组**，每项为 loader 操作行：
   ```yaml
   - insert:
       - id: <唯一插件id>
         name: <npm包名>
         config?: {...}
   ```
   对象式 `{plugins: [...]}` 直接报错。
2. **profile 完全隔离**：`~/.dsh/profiles/alphacopilot/` 独立 package.json + 依赖树，
   默认 `web` profile 的 bundles 未被触碰 —— 满足「一套 preset 启动 AlphaCopilot」要求。
3. `dsh plugin` 本质 pnpm 转发器；本地路径安装用 `-w ./相对路径`（相对调用目录锚定）。
4. 纯 JS 包无需构建脚本即可装；TS 包需自包含 prepare（T12 落实）。

## 清理

```bash
npx @deepseek-ai/dsh plugin --profile alphacopilot remove -w acp-hello-plugin
```
