# S4 Spike — settings.section 整页面板注入（T14a）

结论：**可行**。`settings.section` 槽位按侦察假设工作，web 客户端插件经
`window.__ModuleLoader__.load` classic script + `ctx.slots.inject("settings.section", ...)`
成功把「每日复盘」整页面板注入 dsh web 设置区。mock 数据纯静态，零 RPC。

产物：`packages/dsh-acp-daily-review-demo/`（host 半体 `lib/index.js` +
client 半体 `lib/client.js` + `cordis.patch.yml`）。

## Slot API 实际用法 vs 侦察假设

| 项 | 侦察假设 | 实际 | 差异 |
| --- | --- | --- | --- |
| 注册方式 | `ctx.slots.inject("settings.section", () => ctx.slots.register({name,id,order,label}, Component))` | 同左，逐字照 agent-team-gui/lib/client.js 模式 | 无 |
| options | `{ name, id:"daily-review", order:30, label:()=>"每日复盘" }` | 同左；`inject` 选项省略（无 controller 需求）也合法 | 无 |
| owner props | `SettingsSectionOwnerProps { close }`（slots.d.ts:148） | 组件收到 props 但 mock 页不需要；不消费即无影响 | 无 |
| label 本地化 | registrant-localized，locale 变化时重注册 | 硬编码中文闭包即可点亮导航项 | spike 不接 locale 包，简化 |
| CSS 注入 | `ctx.effect` 注 `<style>`，`:root` 变量 | 同左；dsh alias 变量（`--dsw-alias-*`）可作 fallback 叠加 | 新增发现 |

## 关键坑：package.json exports 必须导出 ./package.json

client 半体被扫描进 boot graph 的链路（`@deepseek-ai/dsh-client-modules`
lib/index.js:377-398）：`createRequire(ctx.baseUrl).resolve("<pkg>/package.json")`。
若包的 `exports` 字段存在但未含 `"./package.json"`，resolve 直接抛
`Package subpath './package.json' is not defined by "exports"`，
`resolveMeta` catch 后静默置 null → 插件从 boot graph **无声消失**（404，
首页 HTML 也无 entry，服务端日志零输出）。修复：

```json
"exports": { ".": "...", "./client": "...", "./package.json": "./package.json" }
```

agent-team-gui 的 exports 里恰好有这行，属隐性契约。已给上游 README
所述「missing files share one build instruction」之外补充此案例。

## CLI 实况与简报差异

- `npx -y @deepseek-ai/dsh --profile alphacopilot web` 在 0.1.1-rc.2 **不可用**：
  `error: web takes none of parent --profile, --patch, ...`。`web` 是独立
  profile 的别名（`dsh web` ≡ `--profile web`），alphacopilot 是 headless 栈。
- 因此插件同时装入两个 profile：alphacopilot（任务要求，dump-config 可证）
  与 web（HTTP 验证所需）。并行任务的 demo 共存正常，互未触碰。

## 已知限制 / 遗留

1. **exports["./package.json"] 隐性契约**：任何带 `exports` 字段的 dsh client
   插件漏掉它即静默失败。T14b 正式面板包必须带上；建议向上游报 issue 加显式报错。
2. **未做 remove 验证**：同 profile 有并行任务行共存，按简报跳过，避免误删他人行。
3. **静态 mock**：不接 RPC/fetch、无 locale 注册（label 单语）、无
   SlotErrorBoundary 包裹（正式版建议照 agent-team-gui 补）。
4. **CLI 差异**：`--profile alphacopilot web` 组合不存在；后续 T18a 联调需确认
   alphacopilot 数据如何进入 web profile 的会话栈（或合并 profile）。
5. 验证用临时服务器已关闭；如需肉眼复核：
   `npx -y @deepseek-ai/dsh plugin --profile web add -w <abs>/packages/dsh-acp-daily-review-demo && npx -y @deepseek-ai/dsh web`。
