# AlphaCopilot — Agent Instructions

AlphaCopilot 是对 [Vibe-Research](https://github.com/simonlin1212/Vibe-Research) 和 [Vibe-Trading](https://github.com/HKUDS/Vibe-Trading) 两个开源项目的个性化整合，不再跟踪上游仓库。

- `Vibe-Research/` — A 股 / 全球行情数据、新闻雷达、AI 研报后端及前端
- `Vibe-Trading/` — AI 驱动的量化交易 agent 框架
